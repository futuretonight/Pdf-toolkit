# PDF Toolkit V3

A full-featured, local, PC-edition document and PDF toolkit offering a wide variety of utilities wrapped in a modern, dark-themed GUI. 

## ✨ Features

pdf toolkit V3 provides a comprehensive suite of modules separated into easy-to-use tabs:

- **⇄ Convert**: Easily convert files between various formats. Supports CSV, XLSX, DOCX, TXT, Images, and PDF.
- **⊟ Compress**: Reduce PDF file sizes efficiently while maintaining readability.
- **✦ Restore**: Repair and restore corrupted or damaged PDF documents.
- **📄 Viewer**: Built-in viewer for previewing your PDF documents in real-time.
- **✂ Split**: Extract specific pages or split large PDFs into multiple smaller files.
- **⊕ Merge**: Combine multiple PDF files, documents, and images into a single PDF document.
- **⊞ Extract**: Pull text, images, and other assets directly from PDF files.
- **⚿ Protect**: Secure your PDFs with password encryption and strict permission constraints.
- **↻ Rotate**: Rotate pages effortlessly.
- **⚡ Crack**: Remove or bypass password restrictions and permissions on PDF files.
- **⚙ Tools & System**: View real-time system resources (CPU/RAM) and access miscellaneous helper tools.
- **🔄 Self-Updating**: Built-in updater directly fetches and applies the latest version from this repository.

## 🚀 Installation & Requirements

The toolkit is built with Python. To install the required dependencies, run the following command:

```bash
pip install pandas pillow reportlab openpyxl python-docx pdf2image pypdf psutil pdfplumber pikepdf docx2pdf tkinterdnd2 pymupdf pypdfium2 numpy opencv-python
```

*(Note: Ensure you have Tkinter installed. On Windows it usually comes with Python, but on Linux you may need to install `python3-tk` or equivalent).*

## 💻 Usage

Simply launch the script using Python:

```bash
python pdftoolkitv3.py
```

The application will open a native window where you can interact with all available tools using the tabbed interface.

## 🔄 Updates

You don't need to manually pull from the repository to update. You can simply click the **Check for Updates** button in the app's top header. The app will fetch the latest code from GitHub, prompt you to install it, and restart itself seamlessly!
